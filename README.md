# Controle Financeiro OPM's

Painel de gastos e saving com freelancers (KVM Pro AV), 2025–2026.

## Como abrir

Baixe o arquivo `index.html` e abra no navegador (Chrome, Edge ou Firefox).
O painel funciona sozinho, sem instalar nada. Os dados estão embutidos no próprio arquivo.

## Telas

- **Visão geral:** saving acumulado, comparação justa entre anos, mapa dos atendimentos e gráficos.
- **Mapa e andamento:** situação de cada ciclo (concluído, em andamento, pendente, programado).
- **Localidades:** tabela por local, com histórico no ritmo de cada unidade (mês, bimestre ou quadrimestre).

## Fonte dos dados

Planilha `Valores - Freelancers - JLD - REV01.xlsx`, aba "Geral (v2 - 2025 preenchido)".
